# Client Onboarding Checklist

> Fictional reference document — Meridian Fulfillment Co.

**Document ID:** SOP-ONB-001
**Owner:** Onboarding Specialists
**Last reviewed:** 2026-02-11
**Standard timeline:** 21 business days from signature to first live order

---

## Phase 1 — Account setup (Days 1–3)

- [ ] Signed agreement received and filed
- [ ] Client record created in NetSuite
- [ ] Rate schedule attached to account (confirm tier: Standard / Growth / Enterprise)
- [ ] Billing contact captured and verified by email
- [ ] Operations contact captured and verified
- [ ] Escalation contact captured — **required, and frequently missed**
- [ ] W-9 or tax documentation on file
- [ ] Insurance certificate received where contract requires
- [ ] Account Manager assigned and introduced

## Phase 2 — Systems (Days 3–8)

- [ ] Client record created in Meridian WMS
- [ ] Integration method confirmed (Shopify / API / EDI / CSV / manual)
- [ ] Integration credentials exchanged securely — **never by plain email**
- [ ] Test connection successful
- [ ] Order flow tested end to end with at least 3 test orders
- [ ] Inventory sync verified in both directions
- [ ] Client portal accounts created for all named users
- [ ] Carrier accounts configured (Meridian rates or client-owned)
- [ ] Zendesk organization created and contacts linked

## Phase 3 — Product setup (Days 5–12)

- [ ] SKU master received in the required template
- [ ] SKU data validated: dimensions, weight, unit cost, barcode
- [ ] SKUs with missing dimensions flagged and resolved — **this is the single most
      common cause of onboarding delay**
- [ ] Lot or serial tracking requirements confirmed per SKU
- [ ] Hazmat classification confirmed where applicable
- [ ] Storage type assigned per SKU (pallet / shelf / bin)
- [ ] Packaging requirements documented
- [ ] Kitting or assembly instructions documented with photos
- [ ] Special handling noted (fragile, temperature, orientation)

## Phase 4 — Inbound (Days 10–18)

- [ ] Initial inbound scheduled with the receiving facility
- [ ] ASN submitted and validated
- [ ] Appointment confirmed with carrier
- [ ] Receiving team briefed on any special handling
- [ ] Product received and putaway complete
- [ ] Inventory reconciled against ASN
- [ ] Any discrepancy resolved per SOP-REC-004

## Phase 5 — Go live (Days 18–21)

- [ ] Pick, pack, and ship tested with live-configuration test orders
- [ ] Packaging verified against client specification
- [ ] Insert and branding requirements verified
- [ ] Shipping labels and tracking flowing back correctly
- [ ] Client walkthrough of the portal completed
- [ ] SLA and escalation path reviewed with client, in writing
- [ ] Billing cycle and first invoice date explained
- [ ] First live order shipped and confirmed
- [ ] 7-day check-in scheduled

## Phase 6 — Handoff (Day 21+)

- [ ] Account file complete and transferred to the Account Manager
- [ ] Open items documented with owners and dates
- [ ] 30-day review scheduled
- [ ] Onboarding retro logged — what delayed this one?

---

## Common delay causes

Tracked across onboardings; presented so specialists can front-load the risk.

1. **Incomplete SKU dimension data** — by far the largest cause. Request it in week 1
   and validate immediately rather than accepting the file at face value.
2. **Integration credentials delayed on the client side.**
3. **Missing escalation contact** — usually surfaces only when it's needed.
4. **Inbound arriving before systems are ready**, forcing quarantine.
5. **Undocumented packaging expectations** discovered at first ship.
